# Документация Дизайна T-NUA Studio (Design System & Guidelines)

Этот документ описывает визуальный язык, дизайн-систему и интерактивные стандарты веб-сайта **T-NUA Studio**. Он служит руководством для поддержки консистентности интерфейса при добавлении новых страниц, разделов или компонентов.

---

## 1. Концепция и Философия (Show. Don't Tell)

* **Стиль:** Премиальный, футуристичный, технологичный (сочетание киберпанк-минимализма и стекла/Glassmorphism).
* **Атмосфера:** Темная тема с яркими неоновыми акцентами, передающая ощущение цифрового искусства, 3D-графики и виртуальной реальности.
* **Интерактивность:** Микро-анимации наведения (hover-эффекты), плавные переходы, интерактивные фильтры и динамическая трехмерная сцена на главном экране.

---

## 2. Цветовая палитра (Color Palette)

Все основные цвета зафиксированы в CSS-переменных в [enhancements.css](file:///d:/Projects/www.T-nua/Tnua/css/enhancements.css) для обеспечения гибкости и глобального контроля темы.

| Переменная | HEX-код | Назначение / Описание |
| :--- | :--- | :--- |
| `--bg-a` | `#0E1D22` | Глубокий темно-бирюзовый (основной цвет градиента фона) |
| `--bg-b` | `#10262D` | Темно-сине-зеленый (второй цвет градиента фона) |
| `--mint` | `#4EF0C3` | Яркий неоновый мятный (основной акцент, интерактивные элементы, ключевой свет в 3D) |
| `--sky` | `#6DDCFF` | Неоновый голубой (вспомогательный акцент, заполняющий свет в 3D) |
| `--text` | `#E6F5F1` | Мятно-белый (основной цвет текста с высокой контрастностью) |
| `--muted` | `#A4C0BA` | Приглушенный серо-зеленый (второстепенный текст, описания, неактивные элементы) |

### Градиенты и Фоновые заливки
* **Фон страниц:** `linear-gradient(135deg, var(--bg-a), var(--bg-b))`
* **Градиент текста заголовков:** `linear-gradient(135deg, #ffffff, #66FFE2)` (или с добавлением переливов)
* **Светящиеся рамки:** `linear-gradient(135deg, rgba(78, 240, 195, 0.5), rgba(109, 220, 255, 0.3))`

## 3. Типографика (Typography)

Используется три основных семейства шрифтов, импортируемых из Google Fonts:

1. **`Space Grotesk` (sans-serif)** — используется для главного заголовка H1 на Hero-секции. Обладает технологичным, геометрическим характером.
2. **`Sora` (sans-serif)** — используется для заголовков разделов (`.section-title`), карточек и важных акцентов. Отличается выразительными округлыми формами.
3. **`Inter` (sans-serif)** — используется для основного текста, описаний и элементов навигации. Обеспечивает великолепную читаемость при любых размерах.

### Правила и стилизация текста
* **Fluid Typography:** Размеры заголовков используют функцию `clamp()` для адаптивности без резких скачков (например, `.section-title` имеет размер `clamp(2rem, 5vw, 4rem)`).
* **Эффект градиентного текста:** Для ключевых заголовков применяется обрезка фона по тексту:
  ```css
  background: linear-gradient(135deg, #ffffff, #66FFE2);
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  ```

## 4. Визуальные эффекты и Компоненты

### Стекломорфизм (Glassmorphism / `.glass`)
Применяется для ключевых контентных блоков (например, приветственная панель в Hero-секции).
* **Эффект размытия:** `backdrop-filter: blur(16px) saturate(1.2)` (с обязательным вендорным префиксом `-webkit-`).
* **Граница с внутренним свечением:** Задается через псевдоэлемент `::before` с маской (`mask-composite: exclude`), создающей эффект тонкого светящегося ребра.
* **Анимации свечения:**
  * `edgeGlow` — мягкое циклическое изменение прозрачности светящейся границы.
  * `gloss` — легкое смещение глянцевых бликов по вертикали.

### Интерактивные карточки (Cards)
Используются в разделах Services, Projects и Blog.
* **Эффект подъема:** При наведении карточка смещается вверх (`transform: translateY(-8px)`).
* **Свечение рамок:** На ховере рамка карточки становится ярче благодаря проявлению градиента (`opacity: 1` у маскированной рамки).
* **Интерактивные медиа:** Если в карточке есть видео или изображение, при наведении на карточку масштаб медиафайла увеличивается на 5% (`transform: scale(1.05)`), создавая ощущение глубины.

### Кнопки и Ссылки (Buttons & CTAs)
* **Контурные/акцентные кнопки (`.btn`, `.cta`):**
  * Скругление углов (`border-radius: 14px` для стандартных или `50px` для овала).
  * Эффект скользящего блика при наведении:
    ```css
    .btn-primary::before {
        content: '';
        position: absolute;
        top: 0; left: 0; width: 100%; height: 100%;
        background: linear-gradient(90deg, transparent, rgba(255, 255, 255, 0.25), transparent);
        transform: translateX(-110%);
        transition: transform 0.5s ease;
    }
    .btn-primary:hover::before { transform: translateX(110%); }
    ```
* **Ссылки с подчеркиванием (`.nav-link`):**
  * При наведении под ссылкой плавно разворачивается градиентная линия от центра или слева направо (`width: 100%`).

### Scroll Progress Indicator
* Закрепленная полоса в самом верху экрана (`position: fixed; top: 0; left: 0; height: 3px;`), заполняющаяся по мере прокрутки страницы градиентом от `--mint` к `--sky`.

## 5. Трехмерная сцена (3D Hero Background)

На главном экране позади текстовой панели рендерится интерактивный 3D-фон.
* **Технология:** Three.js.
* **Объект:** Анимированная модель `assets/3d/t-nua.glb` с автозапуском всех встроенных анимаций через `THREE.AnimationMixer`.
* **Камера:** Камера направлена ортогонально сверху вниз (`PerspectiveCamera`, фокусное расстояние `75mm`, имитирующее физический телеобъектив для минимизации перспективных искажений).
* **Освещение (Three-Point Lighting):**
  1. *Ambient Light:* Мягкий рассеянный белый свет (интенсивность `0.7`) для сохранения цвета теневых участков модели.
  2. *Key Light:* Направленный мятный свет `0x4ef0c3` (интенсивность `3.0`) справа-сверху.
  3. *Fill Light:* Направленный голубой свет `0x6ddcff` (интенсивность `1.6`) слева-сверху.
  4. *Rim Light:* Контровой белый свет `0xffffff` (интенсивность `0.4`) снизу сцены.

## 6. Адаптивность и Доступность (Responsive & Accessibility)

* **Макет:** Построен на гибких сетках CSS Grid (`repeat(auto-fit, minmax(320px, 1fr))`) и Flexbox.
* **Мобильная оптимизация:** На экранах уже 768px навигационное меню сворачивается в бургер-меню, а трехмерная сцена уменьшается в масштабе или адаптируется под меньшую высоту экрана.
* **Экономия ресурсов и снижение движения:**
  При включенной системной настройке уменьшения движения на устройстве пользователя (`prefers-reduced-motion: reduce`) все циклические анимации свечения стекла и движения 3D-сцены автоматически отключаются:
  ```css
  @media (prefers-reduced-motion: reduce) {
      .glass::before, .glass::after { animation: none !important; }
      .glass { filter: none; }
  }
  ```
